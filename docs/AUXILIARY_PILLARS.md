# 胎元、命宫、身宫（v0.4.0）

## 口径与边界

默认方法标识 `jie-month-five-tigers-v1`：节令月支、输入时支、年干五虎遁。
这是有公开实现可核对的传统辅助排法，未声称有使用率调查支持“最多人用”，也不是各派统一标准。
已有四柱仍恰好四柱；辅助坐标独立输出，绝不加入旺衰、信号图、结构评分、流运激活或事件判断。
可选关系分析只列各辅助柱与四个原局柱的天干合、地支冲/合/害，不推合化、不加分，也不推身体健康、寿夭或具体事件。

## 明确公式

天干以甲=0…癸=9，地支以子=0…亥=11。
令 M 为输入月支在寅=1…丑=12中的序号，H 为输入时支在同一序列中的序号，Z 为时支在子=0…亥=11中的序号，Y 为输入年干序号。

- 胎元：月干顺推一位，月支顺推三位，分别循环
- 命宫序号：`1 + ((13 - M - H) % 12)`，序号映射寅…丑
- 身宫序号：`1 + ((M + Z) % 12)`，序号映射寅…丑
- 命/身宫天干：宫序号 P 的天干索引为 `(2*(Y+1)+P-1) % 10`（五虎遁）

例如甲子年、戊辰月、甲戌时：命宫丁卯，胎元己未。
日干只用于附属十神、十二长生标注；并不参与三柱推导。
每柱的 `void` 是该辅助柱自身所属旬的空亡，不能直接解释为该柱“落入命主空亡”。

## 历法假设

- 直接信任调用方给定的年/月/时柱。本库不从出生日期或地点自动排盘
- 自动公式把月支当作节令月建，寅月为一。这里不是农历月份，不设置闰月规则
- 不实现中气过宫、太阳躔度或紫微斗数的命/身宫算法；不能混称
- 年干由输入年柱取得，立春边界由排盘上游处理
- 时区、夏令时、平太阳时/真太阳时、早晚子时换日均由调用方先处理。不会根据地区或时间戳偷偷换算
- 不校验四柱是否对应某一真实公历时刻；它是给定干支的确定性计算
- 胎元是传统符号坐标，不是医学受孕日期

不同口径可用 `overrides` 覆盖任意或全部辅助柱。必须附 `source` 说明；输出同时保留 `calculatedText` 与实际 `text`，避免覆盖结果被误称本方法自动计算。

## 使用

Python：`auxiliary_pillars(chart, include_relations=True)`；从包顶层导入。
协议/CLI 默认保持原 v1 输出；加 `"auxiliary": true` 启用独立输出。
`"auxiliary": {}` 同样启用；`false` 关闭。
完整例子见 `examples/auxiliary_pillars.json`。

选项只有 `method`、`includeRelations`、`overrides`。未知方法/选项、非法干支和无来源的覆盖会报错。
`overrides` 键为 `taiYuan`、`mingGong`、`shenGong`，值如 `{"pillar":"甲子","source":"用户提供的另一派排盘结果"}`。
本版不把辅助分析加入自然语言事件叙述，避免暗中扩大推断范围。
